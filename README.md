# Лабораторна робота №1: Підхід Data-Oriented Programming (DOP) у Java

## Опис проєкту
Проєкт демонструє практичне застосування парадигми Data-Oriented Programming (DOP) у середовищі Java 21:
- Моделювання незмінних даних за допомогою `record`.
- Побудова закритої ієрархії типів через `sealed interface`.
- Обробка повідомлень за допомогою `switch expression` з Record Pattern Matching.
- Форматування результату за допомогою текстових блоків (Text Blocks).

## Розрахунок варіанта
Визначення варіанта згідно зі специфікацією:
$$V = N \pmod 3$$

де:
- $V$ — номер варіанта ($V = 2$, Система обробки сповіщень `Notification`)
- $N$ — номер у списку групи

## Архітектура та структура пакетів
Усі сутності розміщені в пакеті `ua.kpi.comsys.dop`:
- `Notification` — закритий інтерфейс (`sealed interface`).
- `TextMsg`, `ImageMsg`, `AudioMsg` — незмінні записи даних (`record`) із валідацією аргументів у компактних конструкторах.
- `NotificationProcessor` — клас бізнес-логіки обробки та форматування сповіщень.
